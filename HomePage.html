Inclusion of CSS in HTML

There are four ways to associate styles with the HTML document. Most commonly used methods are Inline CSS and External CSS.

Internal/Embedded CSS

We can put the CSS rules into an HTML document using the <style> element. This <style> element is placed inside the <head> ... </head> tags.

Inline CSS

We can use the style attribute of any HTML element to define style rules. These rules will be applied to a particular element only

External CSS

The <link> element is used to include an external stylesheet file in the HTML document. An external style sheet is a separate text file with .css extension.

External CSS library, via CDN (Bootstrap)

The external CSS can be used to refer and apply style rules from the style sheets that are available on CDN (Content Delivery Network).
